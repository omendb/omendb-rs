**Affected Functions:**

| Function                  | Lines     | Issue                                                             |

| `_bench_sq8_via_accessor` | 2472-2527 | `sq8_accessor()` removed                                          |

**Root Cause:** SQ8 was refactored to use `UniformScalarParams`. The benchmark functions reference the old API:

- `ScalarParams::quantize()` now returns `QuantizedVector`, not `Vec<u8>`
- `ScalarParams::asymmetric_l2_squared()` was removed
- `VectorStorage::sq8_accessor()` was removed

**Fix Required:** Either:

1. **Remove functions** (simplest) - These are internal benchmarks not exposed to users
2. **Update to new API** - Use `UniformScalarParams` instead

## Code Review

### SQ8 Scalar Quantization (`src/compression/scalar.rs`)

**Status:** CORRECT

The simplification from per-dimension to uniform quantization is sound:

1. **Algorithm:** Single scale/offset for all dimensions, enabling integer SIMD
2. **Training:** Uses 1st/99th percentiles to handle outliers
3. **Distance:** L2 decomposition with SIMD integer dot product
4. **NEON:** 4x unrolled loop with `vpadalq_u16` for ILP
5. **AVX2:** `madd_epi16` for pairwise multiply-add

Performance validated: 2.4-3.1x faster than FP32 (768D), ~97% recall.

### FastScan SIMD (`src/compression/fastscan.rs`)

**Status:** CORRECT

1. **Overflow prevention:** Line 97 calculates safe max per nibble
2. **Interleaving:** Correct layout for SIMD parallel LUT lookups
3. **NEON:** Uses `vqtbl1q_u8` for 16-way parallel lookup
4. **AVX2:** Uses `_mm256_shuffle_epi8` (pshufb) for LUT lookup
5. **Scalar fallback:** Present for non-SIMD platforms
