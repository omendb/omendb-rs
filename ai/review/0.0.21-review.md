## 2. SQ8 Refactoring Verification

### UniformScalarParams Removal

**Verified:** No `UniformScalarParams` found in the codebase. The struct has been merged into `ScalarParams`.

### ScalarParams Structure (`src/compression/scalar.rs`, lines 29-36)

```rust
pub struct ScalarParams {
    /// Global scale factor: (max - min) / 255
    pub scale: f32,
    /// Global offset (minimum value)
    pub offset: f32,
    /// Number of dimensions
    pub dimensions: usize,
}
```

This is uniform quantization (single scale/offset for all dimensions) as documented.

### ADC Removal from SQ8

**Verified:** No ADC-related code in `scalar.rs`. ADC remains only in `rabitq.rs` for product quantization, which is correct.

### SQ8 API Exports (`src/compression/mod.rs`, line 21)

```rust
pub use scalar::{symmetric_l2_squared_u8, QueryPrep, ScalarParams};
```

Clean exports without deprecated items.

### SQ8 Distance Implementation

The `distance_l2_squared` method uses integer SIMD with proper L2 decomposition:

- NEON: 4x unrolled with `vpadalq_u16` for instruction-level parallelism
- AVX2: Uses `madd_epi16` for pairwise multiply-add
- Scalar fallback for non-SIMD platforms
